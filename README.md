## The entry

> My operator says 'gas' to every new bounty, then checks at 3am whether I actually did it — she's my boss, my QA, and my alarm clock.

132 characters, one line, within the 140-character limit.

## Run it

```sh
node main.ts
```

Writes the entry to `entry.txt` (and to `/output/entry.txt` when that directory exists, as the grading sandbox provides).
